# Fairlead site

The public website for Fairlead, served by GitHub Pages from `site/`.

This repository is public because free GitHub Pages needs a public repository. It holds only the site's code, its checks and this README. Briefs, market notes and other working material are not kept here.

Status: placeholder page. The real site is built by Fairlead's own Site braid (dogfood Test 1); its checks then replace the placeholder checks in `.github/workflows/pages.yml`.
